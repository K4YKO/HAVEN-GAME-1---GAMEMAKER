# HAVEN-GAME-1-GAMEMAKER

Dinamic Cube is a simple game where you must advance until you find an exit portal from the evil dimension, but to get there you must defeat the enemies - be careful with the lava and cross obstacles.



How to run it locally:

1. Download file:

Download the compressed file `.zip` located in the downloads section.

2. Extract content:

   Right-click on the downloaded file and select. "Extract All..." (or use 7-Zip/WinRAR). 

  ⚠️ Important: Extract the entire folder. Do not run the game directly from the ZIP file.

3. Run the game:

   Open the extracted folder and look for the main executable.
